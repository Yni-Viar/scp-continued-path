# SCP: Continued Path

Available on [GameJolt](https://gamejolt.com/games/scpcontpr/998566), [itch.io](https://yniviar.itch.io/scp-continued-path)

## About

SCP: Continued Path is a 3rd-person singleplayer Research-simulator SCP game.
Enjoy the short story about Janusz Krzystofski, the senior researcher of Site-19... Choose your path of story!
Or do your daily job in Casual Mode - you need to study anomalies, such as SCP-067, SCP-812, and others.

Click/Tap - move/pick items (if you tap on character, they will go with you).

More gestures you can see in the in-game settings.

[💳Support the author financially!](https://boosty.to/yniviar)

## Requirements to play

- 🐧Linux distribution from 2024 and newer

   > x86-64 or arm64 binaries available

- 🪟Windows 10 (all updates (build 14393 and higher is recommended)) and 11 (all updates)
   > x86-64 or arm64 binaries available

   > Windows 8.1 is not natively supported since v10.0

   > Windows 7 and 8 is not natively supported since v5.0

   > You can still access Web version for Windows 7 - 8.1 by using Supermium.

- 🤖Android 7.0 and newer (mid-range device)

   > arm64 and armv7 binaries available

   > Android 5.0-6.0 is not supported since v5.0
   

- 🌐Modern browser (Chromium-based, Firefox and Edge)

   > Web version is **experimental**!!!

   > Instance, hosted on GameJolt or itch.io, supports only PCs, due to the game size.

- 🖥️ Hardware requirements
   - OpenGL 3.3/ES 3.0 minimum, Vulkan support recommended
   - display resolution > 1280x720 (except Android) recommended
   - Mouse/touch or keyboard support.
