---Why this name?---

I named the file "bientot" ("bientôt", which means "soon" in French), because in the full version of the photo a couple was depicted who made the game "Bientôt l'été" ("The summer is soon"), as well, as "The Endless Forest" and "The Path".

I LOVE their works, so I made a tribute!
